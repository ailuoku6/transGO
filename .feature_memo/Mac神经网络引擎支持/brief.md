# 目标与范围

用户希望项目支持 Mac NPU，并指出目前似乎没有使用该硬件。

本轮接入可选 Core ML CPU_AND_NE 网络推理，覆盖自博弈、评估、loop 推理阶段、人机对弈、GTP、JSON-RPC 和 benchmark。增加可选依赖、缓存、批处理、诊断和本机基准。

不迁移训练或反向传播到 NPU；不改原权重、训练目录、默认后端、checkpoint/replay schema，不停止或重启用户进程。

验收：真实 Core ML 预测可用、全部预测头和合法 mask 保持接口兼容、集中合批和临时完整闭环通过；依赖/平台/运行失败明确报错，不能静默改用 PyTorch。

局部基准不能证明完整训练加速、功耗收益或棋力提升。
